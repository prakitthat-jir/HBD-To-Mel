## 4. Tech Stack & Guidelines for AI Generation (คำสั่งสำหรับ AI)

### 4.1 Preferred Technology
- **Single Page Application (SPA):** ต้องการเน้นเขียนจบในไฟล์เดียว หรือโครงสร้างที่ไม่ซับซ้อน (เช่น HTML + Tailwind CSS + JavaScript Vanilla หรือ React/Next.js)
- **UI Framework/Library:** ใช้ **Tailwind CSS** เพื่อความสวยงาม และ **Framer Motion** หรือ **Canvas-Confetti** สำหรับแอนิเมชัน (ถ้าเป็น React)

### 4.2 Design & UX Requirements
- **Responsive:** ต้องรองรับการแสดงผลบนมือถือ (Mobile-First) เป็นหลัก เพราะเพื่อนน่าจะเปิดดูผ่านโทรศัพท์
- **Animations:** มี transition นุ่มนวล เช่น การจางเข้า (Fade-in), การเด้งของปุ่ม (Hover/Active effect), และมี Confetti (พลุกระดาษ) เด้งตอนกดดูคำอวยพร
- **Clean Code:** เขียนโค้ดอ่านง่าย แยกส่วนประกอบ (Components) ชัดเจน และมี Comment อธิบายจุดที่ต้องเปลี่ยนรูปภาพหรือข้อความ
