# HBD-To-Mel

เว็บอวยพรวันเกิดภาษาไทยแบบ static ใช้ `index.html` และไฟล์ประกอบใน `assets/` เปิดผ่าน GitHub Pages ได้โดยไม่ต้อง build ส่วน Tailwind และฟอนต์โหลดจาก CDN

## ตั้งค่าและเนื้อหาที่ยังต้องเติม

- แก้คำอวยพรและคำถามที่ `MAIN_WISH`, `SHORT_WISH`, `WISH_POOL` และ `QUIZ`
- แกลเลอรีมีรูปจริง 18 รูป จัดเป็นกริดโพลารอยด์เรียงตามลำดับ พร้อมเอฟเฟกต์ปรากฏเมื่อเลื่อนหน้าและเอียงตามเมาส์ เปิดดูภาพเต็มแบบเปลี่ยนภาพนุ่มนวล ลาก/ปัดซ้ายขวา เลือกจากแถบรูปย่อ เลื่อนด้วยปุ่มหรือลูกศร และปิดด้วย Escape รองรับการลดการเคลื่อนไหวตามการตั้งค่าอุปกรณ์ แก้ลำดับ/แคปชั่นได้ที่ `assets/memories.js`
- รูปสำหรับเว็บอยู่ใน `assets/photos/` เป็น WebP ขนาด 640 และ 1440 พิกเซลด้านยาว ใช้ lazy loading และ srcset; ต้นฉบับในโฟลเดอร์ `รูป/` คงไว้ในเครื่อง
- เพลงคลอใช้ `<audio>` และ `assets/music.js` โดยวางไฟล์เพลง “ยินดีที่ไม่รู้จัก” ชื่อ `music.mp3` ข้าง `index.html` (แยกเสียงจากไฟล์วิดีโอที่ผู้ใช้ส่งมา ความยาวประมาณ 3 นาที 19 วินาที) ตั้งเสียงเริ่มต้น 22% และวนซ้ำ มีเฉพาะปุ่มเสียงมุมจอ ใช้ได้ตั้งแต่หน้าล็อก ไม่มีแผงเพลงหรือวิดีโอ
- เว็บพยายามเล่นตั้งแต่เปิดหน้า หากเบราว์เซอร์บล็อก autoplay จะลองใหม่เมื่อผู้ใช้แตะหรือกดแป้นพิมพ์ เมื่อกดปิดเพลงแล้ว การแตะส่วนอื่นจะไม่เปิดเพลงกลับเอง ต้องกดปุ่มเสียงอีกครั้ง
- เฉลยข้อ 5 คือ E “หนังตลกมันทางของพี่”
- `CONFIG.password` เป็นลูกเล่นหน้าต้อนรับ รหัสและเนื้อหาอ่านได้จาก source จึงไม่ใช่ระบบป้องกันข้อมูลส่วนตัว
- `REMOTE` เชื่อมกับ Google Apps Script; โค้ดตัวอย่างและวิธี deploy อยู่ใน `index.html` คอมเมนต์ที่ส่งจะเผยแพร่ให้ผู้เข้าชมคนอื่นเห็นเมื่อ `showOthers: true`
- Brief ในโฟลเดอร์ `HBD/` ระบุเฉลยอายุข้อ C แต่โค้ดปัจจุบันเป็นข้อ D ควรให้ผู้สร้างยืนยันเนื้อหาที่ต้องการก่อนเปลี่ยนเฉลย

## ตรวจสอบด้วยเบราว์เซอร์

Chapter 3 แยกสองขั้นตอน: แต่งเค้ก → Show cake โดยใช้เค้ก 3D ก้อนเดียวกันตลอด เริ่มจากเค้กเปล่า เลือก 1–3 ชั้น แต่ละชั้นเลือกรสชาติและ 1–4 เลเยอร์พร้อมไส้แยกกันได้ มีสตรอว์เบอร์รี ช็อกโกแลต วานิลลา มัทฉะ นม โอริโอ้ มัทฉะลาเต้ และกาแฟ รสโอริโอ้มีเศษคุกกี้บนเนื้อเค้ก มัทฉะลาเต้มีแถบนม และเลือกเปิด/ปิดป้ายดาวได้

ตู้ของตกแต่งแสดงภาพและโมเดลหมุนได้จาก geometry/material เดียวกับของจริงบนเค้ก ใช้ renderer เพิ่มเพียงหนึ่งตัวสำหรับตู้ทั้งหมด มี 13 แบบ รวมโอริโอ้ มาการอง หัวใจ ดาว และบลูเบอร์รี เลือกขนาดก่อนวางได้ รายการชิ้นที่วางแล้วช่วยเลือกและลบชิ้นที่อยู่ด้านหลังหรือซ้อนกันได้ พร้อมทำสำเนา ย้าย หมุน ปรับขนาด ลบเส้นครีมทีละเส้น Undo และชุดจัดตกแต่งอัตโนมัติ 3 แบบที่ยังแก้ทีละชิ้นได้

กด Show cake เพื่อเปิดไฟกาล่าและจุดเทียนตามจำนวนที่อยู่บนเค้ก แตะเทียนชิ้นนั้นหรือปุ่มเป่าเพื่อดับทีละเล่ม มีตัวนับ ควัน และเอฟเฟกต์ฉลองเมื่อครบ หลังเป่าหมดจึงไปต่อจดหมายได้ กรณีไม่วางเทียนสามารถไปต่อได้ทันที จุดใหม่หรือกลับไปแต่งต่อได้โดยไม่สูญเสียเค้ก บันทึกภาพ PNG 1600 × 1300 พิกเซลจากมุมปัจจุบันได้ทั้งสองขั้นตอน รองรับมือถือ การลากหมุน สองนิ้วซูม แป้นพิมพ์ และลดการเคลื่อนไหว

ใช้ Three.js ใน src/cake3d.js โหลดเฉพาะเมื่อเข้าหน้าเค้ก และหยุดวาดเมื่อซ่อนหน้าหรือแท็บ เครื่องที่ไม่มี WebGL จะใช้เค้ก 2D สำรองซึ่งรองรับการแต่งพื้นฐานและขั้นตอนโชว์/เป่าเทียน

หลังแก้ src/cake3d.js รัน npm run build:cake และ commit assets/cake3d.bundle.js ด้วย GitHub Pages ไม่ต้อง build เพิ่ม ใบอนุญาต Three.js อยู่ใน assets/THREE-LICENSE.txt

แคปชั่นแต่ละรูปมีปุ่มแก้ไขและบันทึกในเบราว์เซอร์เครื่องปัจจุบัน ไม่ซิงก์ข้ามเครื่อง หากต้องการเปลี่ยนข้อความเริ่มต้นสำหรับผู้เข้าชมทุกคน ให้แก้รายการ photos ใน assets/memories.js แล้ว push ขึ้น GitHub

ใช้ Node.js 20 ขึ้นไป:

```sh
npm ci
npx playwright install chromium
npm test
```

หากมี Microsoft Edge อยู่แล้ว บน PowerShell ใช้ `$env:PLAYWRIGHT_CHANNEL='msedge'` ก่อน `npm test` เพื่อใช้ Edge แทน Chromium ที่ดาวน์โหลดเพิ่ม

ชุดทดสอบเปิดเว็บผ่าน HTTP ในเครื่อง ตรวจ flow ตั้งแต่รหัสผ่าน ควิซ สรุปผล เค้ก จดหมาย และธีม ที่ความกว้าง 1280 และ 390 พิกเซล พร้อมทดสอบ HTML injection, การกดซ้ำ, คอมเมนต์ที่โหลดช้า, การตอบปฏิเสธจากเซิร์ฟเวอร์, คิวรอส่ง และ storage เต็ม รูปหน้าสรุปจากการทดสอบอยู่ใน `test-results/`

ทุก request ไป Google Apps Script ถูกจำลองระหว่างทดสอบ จึงไม่มีการส่งข้อมูลทดสอบไปชีตจริง และผลทดสอบนี้ไม่ได้ยืนยันสิทธิ์หรือสถานะ deployment ของ Apps Script จริง การทดสอบเพลงใช้ไฟล์ WAV เงียบที่สร้างในหน่วยความจำเพื่อตรวจ native audio, autoplay, การวนซ้ำ และปิดเสียง รวมถึงกรณีไม่พบไฟล์เพลง และมีกรณีทดสอบ music.mp3 จริงผ่านเบราว์เซอร์ โดยตรวจการเล่น การวนกลับต้นเพลง และการปิดเพลง

## ข้อจำกัดการซิงก์

ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ หากเขียนไม่ได้จะใช้หน่วยความจำชั่วคราวแทน รายการที่ทราบว่าส่งไม่สำเร็จจะเข้าคิวและลองอีกครั้งเมื่อโหลดหน้าใหม่หรือกลับมาออนไลน์

หาก POST ส่งออกไปแต่เบราว์เซอร์อ่านผลไม่ได้ เช่น CORS หรือการเชื่อมต่อขาดระหว่างรับผล ระบบจะรายงานว่ายืนยันไม่ได้และไม่ POST ซ้ำทันที เพราะเซิร์ฟเวอร์อาจบันทึกไปแล้ว สำเนาคอมเมนต์และประวัติควิซยังอยู่ในเครื่อง การรับประกันส่งครบโดยไม่ซ้ำต้องเพิ่ม request ID และการตรวจรายการซ้ำใน Apps Script ด้วย

## ย้อนกลับระหว่าง Chapter

แถบด้านบนและปุ่มก่อนหน้า/ถัดไปเปิดกลับไปยัง Chapter ที่เคยเข้าถึงแล้วได้ โดยคงสถานะเค้ก จดหมาย และคำตอบที่กำลังทำในหน้าเดิมไว้ Chapter ที่ยังไม่เคยไปต้องผ่านเส้นทางหลักก่อน ควิซที่ทำเสร็จเปิดเป็นสรุปคำตอบทั้ง 10 ข้อแบบอ่านอย่างเดียว การกลับไปหน้าเริ่มต้นไม่เริ่มควิซใหม่และไม่เพิ่มคะแนน/ประวัติหรือส่งข้อมูลซ้ำ คำตอบที่ส่งแล้วบันทึกใน localStorage เพื่อให้รีเฟรชแล้วเริ่มต่อจากข้อที่ยังไม่ตอบได้ หากเครื่องไม่อนุญาตให้บันทึกจะเก็บได้เฉพาะระหว่างเปิดหน้านั้น

แคปชั่นที่แก้ในเบราว์เซอร์ยังเป็นข้อมูลของเครื่องนั้น ปุ่ม “ดาวน์โหลดแคปชั่นล่าสุด” ส่งออกทั้ง 18 รูปเป็น mel-latest-captions.json โดยใช้ข้อความในช่องแก้ไขล่าสุดรวมถึงข้อความที่ยังไม่กดบันทึก ไฟล์นี้ใช้ส่งให้ผู้สร้างอัปเดตค่าเริ่มต้นใน assets/memories.js เพื่อเผยแพร่ข้อความเดียวกันให้ทุกคนเห็น ปุ่มดาวน์โหลดไม่เผยแพร่แคปชั่นเอง
