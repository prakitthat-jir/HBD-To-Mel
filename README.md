# HBD-To-Mel

เว็บอวยพรวันเกิดภาษาไทยแบบ static ใช้ HTML, CSS และ JavaScript ใน `index.html` เปิดผ่าน GitHub Pages ได้โดยไม่ต้อง build ส่วน Tailwind และฟอนต์โหลดจาก CDN

## ตั้งค่าและเนื้อหาที่ยังต้องเติม

- แก้คำอวยพรและคำถามที่ `MAIN_WISH`, `SHORT_WISH`, `WISH_POOL` และ `QUIZ`
- แกลเลอรียังเป็น placeholder 6 รูป พร้อมแคปชั่นตัวอย่าง
- เพิ่มไฟล์ `music.mp3` ข้าง `index.html` หากต้องการเปิดเพลงพื้นหลัง
- `CONFIG.password` เป็นลูกเล่นหน้าต้อนรับ รหัสและเนื้อหาอ่านได้จาก source จึงไม่ใช่ระบบป้องกันข้อมูลส่วนตัว
- `REMOTE` เชื่อมกับ Google Apps Script; โค้ดตัวอย่างและวิธี deploy อยู่ใน `index.html` คอมเมนต์ที่ส่งจะเผยแพร่ให้ผู้เข้าชมคนอื่นเห็นเมื่อ `showOthers: true`
- Brief ในโฟลเดอร์ `HBD/` ระบุเฉลยอายุข้อ C แต่โค้ดปัจจุบันเป็นข้อ D ควรให้ผู้สร้างยืนยันเนื้อหาที่ต้องการก่อนเปลี่ยนเฉลย

## ตรวจสอบด้วยเบราว์เซอร์

ใช้ Node.js 20 ขึ้นไป:

```sh
npm ci
npx playwright install chromium
npm test
```

หากมี Microsoft Edge อยู่แล้ว บน PowerShell ใช้ `$env:PLAYWRIGHT_CHANNEL='msedge'` ก่อน `npm test` เพื่อใช้ Edge แทน Chromium ที่ดาวน์โหลดเพิ่ม

ชุดทดสอบเปิดเว็บผ่าน HTTP ในเครื่อง ตรวจ flow ตั้งแต่รหัสผ่าน ควิซ สรุปผล เค้ก จดหมาย และธีม ที่ความกว้าง 1280 และ 390 พิกเซล พร้อมทดสอบ HTML injection, การกดซ้ำ, คอมเมนต์ที่โหลดช้า, การตอบปฏิเสธจากเซิร์ฟเวอร์, คิวรอส่ง และ storage เต็ม รูปหน้าสรุปจากการทดสอบอยู่ใน `test-results/`

ทุก request ไป Google Apps Script ถูกจำลองระหว่างทดสอบ จึงไม่มีการส่งข้อมูลทดสอบไปชีตจริง และผลทดสอบนี้ไม่ได้ยืนยันสิทธิ์หรือสถานะ deployment ของ Apps Script จริง

## ข้อจำกัดการซิงก์

ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ หากเขียนไม่ได้จะใช้หน่วยความจำชั่วคราวแทน รายการที่ทราบว่าส่งไม่สำเร็จจะเข้าคิวและลองอีกครั้งเมื่อโหลดหน้าใหม่หรือกลับมาออนไลน์

หาก POST ส่งออกไปแต่เบราว์เซอร์อ่านผลไม่ได้ เช่น CORS หรือการเชื่อมต่อขาดระหว่างรับผล ระบบจะรายงานว่ายืนยันไม่ได้และไม่ POST ซ้ำทันที เพราะเซิร์ฟเวอร์อาจบันทึกไปแล้ว สำเนาคอมเมนต์และประวัติควิซยังอยู่ในเครื่อง การรับประกันส่งครบโดยไม่ซ้ำต้องเพิ่ม request ID และการตรวจรายการซ้ำใน Apps Script ด้วย
